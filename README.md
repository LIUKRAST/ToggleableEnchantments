# Toggleable Enchantments

Allows via a menu that can be opened with `J` (Can be changed in keybindings)
to enable/disable single enchantments of an item.

Additionally, each enchantment can be configured with a Hotkey Group (1 → 9).
Without opening the menu,
pressing that number on the numpad (can be changed in keybindings)
will automatically toggle all the enchantments bound to the hotkey group. Put the hotkey group on `-` to disable the hotkey function for that enchantment.
